# 基金看板

本地运行的桌面 Web 基金看板，提供持仓收益、基金自选、A股市场概览、主要市场指数、基金详情（规模/经理/费率/持仓/业绩走势）与估值准确率对比。持仓与自选数据仅保存在当前浏览器，后端只负责转发公开行情。

当前版本：`v1.1.0` · [查看更新日志](./CHANGELOG.md)

## 功能特性

- **总览**：持仓成本、市值、当日预估收益、回本所需涨幅。
- **持仓基金**：多组合管理，持仓表格（成本/市值/涨跌/收益），添加/编辑/删除持仓，基金代码/名称模糊搜索，点击基金名打开**基金详情抽屉**。
- **自选基金**：关注列表与实时行情。
- **A股大盘**：涨跌家数、概念板块排行。
- **指数看板**：主要市场指数实时行情与历史走势。
- **估值准确率**：盘中预估与收盘净值的对比统计，每晚 22:00 自动对比，可手动触发。
- **基金详情抽屉**：规模、基金经理、申购/赎回费率分档表（含持有期限赎回规则）、交易确认日、前十大持仓、持仓股实时行情（A股+港股）。
- **业绩走势**：基金累计收益 vs 业绩比较基准的对比曲线，支持近1月/近3月/近6月/近1年/近3年/今年来/成立来 7 个周期切换。
- **数据导入/导出**：JSON 备份与恢复，数据保存在浏览器本地。

## 环境要求

- Windows 10 或更高版本
- Node.js 20 或更高版本（包含 npm）

## 使用

双击根目录下的 `启动基金看板.bat`。程序启动后会自动打开：

```text
http://127.0.0.1:51888
```

保持启动窗口开启。关闭窗口后服务停止。

首次运行会自动安装依赖并构建页面，需要能够访问 npm 软件源和行情数据源。

## 使用 AI Agent 安装

将下面这句话发送给 AI Agent：

> 请从 `https://github.com/hakunamatata5893/fund-dashboard.git` 克隆基金看板项目，在 Windows 环境检查 Node.js 20 及以上版本，进入项目目录后执行 `npm run setup` 安装依赖并构建项目，然后运行 `启动基金看板.bat`，最后确认 `http://127.0.0.1:51888` 可以访问；不要读取、提交或上传任何个人持仓及备份数据。

## 数据备份

- 点击页面右上角“导入 / 导出”。
- “导出数据”会下载 JSON 备份文件。
- 导入有效备份前会展示摘要并要求确认；导入会覆盖当前浏览器中的持仓。
- 清理浏览器站点数据、更换浏览器或更换电脑前，请先导出备份。

## 开发命令

```powershell
npm run setup
npm run test
npm run typecheck
npm run build
npm start
```

开发前端运行在 `51889`，并将 `/api` 代理到本地后端 `51888`。

## 数据与隐私

- 持仓、自选和成本数据保存在浏览器 `localStorage`，不会写入项目目录或上传到服务器。
- 本仓库不包含个人持仓备份；导出的 `fund-dashboard-backup-*.json` 已设置为 Git 忽略文件。
- 公开分享、提交问题或贡献代码前，请勿附带任何个人持仓截图或备份文件。

## 行情说明

项目当前使用以下第三方公开数据源：

- **Fund123**：基金搜索、基金名称、盘中预估净值及预估涨跌。
- **东方财富**：基金正式净值与历史净值、基金类型、持仓信息、业绩比较基准文本、费率规则、A股涨跌家数、概念板块排行、指数实时行情。
- **中证指数官网（csindex.com.cn）**：中证系列指数（000/930/931/H30）全量历史行情，业绩比较基准的首选数据源。
- **腾讯行情**：A股、港股和部分美股指数历史行情的备用来源。
- **新浪财经**：A股指数、北证及部分美股指数历史行情的备用来源。
- **日经指数官网**：日经 225 历史行情的备用来源。
- **Naver Finance**：韩国 KOSPI 历史行情的备用来源。

指数历史行情按“中证官网 → 新浪 → 腾讯 → 新浪美股”的顺序自动兜底，并对过期数据做新鲜度检查。部分无公开历史源的业绩比较基准使用近似标的并在图中如实标注（如 Au99.99 → 华安黄金ETF、恒生港股通中国科技 → 恒生科技指数）。页面中的实时收益和当日预估数据可能因交易时段、净值披露时间及数据源延迟而暂时显示为 `-`。

上述接口均为公开行情接口，并非项目自建或官方授权的稳定服务，可能随时发生延迟、缺失、限流或字段变更。数据仅供参考，不构成投资建议，请以基金公司、交易所及正规行情商披露为准。
